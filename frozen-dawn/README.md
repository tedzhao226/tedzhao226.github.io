# Frozen Dawn guide

A playthrough reference for Call of Duty: WWII Zombies, based on [SchleyerZ’s solo Kingfall walkthrough](https://www.youtube.com/watch?v=45dG6srGVMA), published 7 June 2025 (18:49).
It follows the video’s route across 12 stages, with 48 chapter links and 102 selected 1920 × 1080 screenshots.

## Editing

Edit stage text and screenshot selections in `build.mjs`, presentation in `style.css`, and dialog/navigation behavior in `reader.js`.
`chapters.json` contains the source video’s timestamp index.
Screenshot filenames are video timestamps in seconds; the canonical JPEGs live in `assets/`.
Run `npm run guide:build` from the repository root to regenerate the web and offline HTML editions.
`selected-frames.json` is regenerated by the build and consumed by `package.mjs` to embed images in the offline edition.

## Reference limits

Use the player’s own rune codes, constellation patterns, and blood-pool symbols; screenshots show the creator’s recorded run.
The raven atlas contains 29 viewpoints although the narration says 30; seven gear candidates are shown although the narration says six.
The guide keeps the visible evidence and labels these discrepancies.
The hammer wall section includes both observed first-wall variants plus walls two and three.
Embedded YouTube playback depends on network access and YouTube availability; direct timestamp links remain available.
Screenshots and gameplay belong to their respective owners; preserve the source attribution.
