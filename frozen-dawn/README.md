# Frozen Dawn guide

A playthrough reference for Call of Duty: WWII Zombies, based on [SchleyerZ’s solo Kingfall walkthrough](https://www.youtube.com/watch?v=45dG6srGVMA), published 7 June 2025 (18:49).
It follows the video’s route across 12 stages, with 48 chapter links and 102 selected 1920 × 1080 screenshots.

## Editing

Edit stage text and screenshot selections in `build.mjs`, presentation in `style.css`, and dialog/navigation behavior in `reader.js`.
`chapters.json` contains the source video’s timestamp index.
Screenshot filenames are video timestamps in seconds; the canonical JPEGs live in `assets/`.
Run `npm run guide:build` from the repository root to regenerate the web and offline HTML editions.
`selected-frames.json` is regenerated by the build and consumed by `package.mjs` to embed images in the offline edition.

## Languages

The same web page and offline HTML contain English, Simplified Chinese, Japanese, Korean, Russian, French, and Spanish.
Choose a language at the top, or use a shareable URL such as [Simplified Chinese](https://tedzhao226.github.io/frozen-dawn/?lang=zh-CN).
The other language codes are `ja`, `ko`, `ru`, `fr`, and `es`.
Switching language retains the selected stage; it does not fetch a remote translation service.
The original screenshots and video remain in English.

Translation sources live in `locales/`; `localize.mjs` extracts the English catalog and embeds all dictionaries, and `i18n.js` applies the chosen language to text, captions, accessibility labels, and dialogs.
After changing English source text, run `node frozen-dawn/build.mjs --catalog` from the repo root to refresh the catalog, update all matching locale entries, then run the normal build.
The catalog-only output is an English preview; publish only the normal build containing every language.
Checks reject missing or stale entries, changed markup or links, changed literal numbers, extra numeric quantities, and broken placeholders.
Written-out quantities and translation meaning still need editorial review.

Official PC map, achievement, and Raven names were checked against the [game-supplied Steam achievement text](https://steamcommunity.com/stats/476620/achievements/).
Blitz names and functions were checked against [Activision’s Zombies guide](https://www.callofduty.com/de/blog/archives/the-new-kid-vs-doktor-straub-or-how-i-learned-to-ride-the-waves-and-not-make-my-teammates-hate-me).
The term sources and descriptive equivalents are recorded in `locales/terminology.json`.
Unverified location and equipment labels use descriptive translations with English references; these are fan translations, not an official localized guide.

## Reference limits

Use the player’s own rune codes, constellation patterns, and blood-pool symbols; screenshots show the creator’s recorded run.
The raven atlas contains 29 viewpoints although the narration says 30; seven gear candidates are shown although the narration says six.
The guide keeps the visible evidence and labels these discrepancies.
The hammer wall section includes both observed first-wall variants plus walls two and three.
Embedded YouTube playback depends on network access and YouTube availability; direct timestamp links remain available.
Screenshots and gameplay belong to their respective owners; preserve the source attribution.
